```typescript
// POST /api/v1/auth/login {email,password,rememberMe?} → { user: PublicUser } + Set-Cookie uhhu_session (httpOnly, Secure em prod, SameSite lax)

// GET /api/v1/projects → 200 lista (exige auth; 401 sem sessão/PAT)
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| teclado → app → API | email/senha são hostis até Zod; erro 401 genérico sem oráculo de existência |
| SecureStore → API | PAT é segredo; circula uma vez, repousa cifrado, nunca em log/bundle |
| 401 → redirect | expired/next são UX; autorização real sempre no CORE por request |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03-01 | Spoofing | login nativo sem lockout bypass | mitigate | mesmo contador do servidor (5→15min); client exibe 429 verbatim sem retry automático |
| T-06-03-02 | Information Disclosure | raw do PAT | mitigate | SecureStore só no nativo, memória volátil no web, zero console/log/bundle; logout apaga local + revoga servidor |
| T-06-03-03 | Information Disclosure | enumeração de email | mitigate | 401 genérico sem distinguir email/senha (D-63); reset/register sem oráculo |
| T-06-03-04 | Tampering | privilégio em storage | mitigate | zero localStorage/AsyncStorage para role/owner; guards são UX; requireAuth no servidor |
| T-06-03-05 | Elevation | next redirect aberto | mitigate | next restrito a rotas internas `/...` (rejeita `http`, `//`, `\\`); fallback /projects |
</threat_model>
