## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tela → ApiError | message/requestId exibidos são seguros para cliente (servidor já redige stack/cookies/SQL) |
| bundle web → público | dist/ é pública; qualquer segredo ali é vazamento |
| beta tailnet → API | rede tailnet não é auth; CORS+cookie+requireAuth continuam exigidos |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-04-01 | Information Disclosure | bundle com segredo | mitigate | grep bloqueante em dist + EXPO_PUBLIC só para base URL; Gitleaks tree |
| T-06-04-02 | Tampering | erro genérico que esconde ação | mitigate | ErrorBanner exibe message verbatim + requestId + Repetir que refaz o fetch real |
| T-06-04-03 | Spoofing | skeleton que finge dado | mitigate | skeleton só em loading com testID distinto; nunca confundido com card real |
| T-06-04-04 | Elevation | guarda de frontend como auth | mitigate | guards são UX; prova beta usa curl com/sem cookie mostrando 401 real do servidor |
| T-06-04-05 | Denial of Service | retry infinito | mitigate | Repetir é ação manual por toque; sem auto-retry; polling de runs fica para fase 7 |
</threat_model>
