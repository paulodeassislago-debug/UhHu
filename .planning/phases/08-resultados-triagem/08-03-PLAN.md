<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| groupId → PUT decision/divergence | groupId vem do servidor (memberIds); adulterado → 404; decisão por resultId é proibida no client |
| note → servidor → render | Nota é hostil: client bloqueia `<>`, servidor stripa HTML, render em Text (escapa) |
| originUrl/sourceUrl → Linking | Só abre https; http/javaschema → texto não-tocável |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-03-01 | Tampering | decisão no grupo errado | mitigate | groupId só do DTO; card sem grupo desabilita; override mapado por groupId exato |
| T-08-03-02 | Cross-site Scripting | nota/divergência com HTML | mitigate | bloqueio client + strip server + Text escapa; teste manual `<script>` vira texto |
| T-08-03-03 | Information Disclosure | membro de outro dono via getResult | mitigate | servidor owner-scoped + 404; erro isolado por grupo, sem vazar existência |
| T-08-03-04 | Denial of Service | expandir dispara N gets | mitigate | só membros do grupo (2-3 típico), uma vez por grupo (cache), sem prefetch na lista |
| T-08-03-05 | Repudiation | decisão sem rastro visível | mitigate | decidedAt exibido após cada PUT; requestId em erro; trilha de auditoria server-side futura |
</threat_model>
